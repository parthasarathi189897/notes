## 🔁 Weekly rhythm

```
MON  — Open this week's note. Read goal + course chunk.
WED  — Mid-week pulse. 30 min lab/code.
FRI  — Course lessons + concept notes.
SUN  — Retro: what worked, what to adjust, mark tracker.
```

If you miss a week: do **not** double up. Slip the timeline by one week and move on. Streak > sprint.
