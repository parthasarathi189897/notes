## 🎯 What I'm shipping

One polished, deployed, evaluated product combining everything.

**Backend (Python + FastAPI):**
- Document upload + ingestion + chunking + embedding
- Vector search + RAG generation with citations
- Eval harness integration (install P5 as package)
- Structured logging, cost + latency tracking, failure log

**Frontend (React or Next.js — leverage 15y FE experience):**
- Document upload UI
- Chat / search with streaming
- Clickable citation viewer
- Eval dashboard (golden set status, scores, trends)
- Cost meter

**Quality:**

- Retrieval relevance + groundedness + correctness metrics
- CI eval gates deploys (wire P8)
