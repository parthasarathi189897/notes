# Study — Quick Reference

## Study Paths

All study is path-based. Each path is a self-contained folder in `study/`.

| Path | Folder | Tracker |
|------|--------|---------|
| AI Engineering Path | `study/ai-engineering-path/` | `02-progress-tracker.md` |
| System Design Interview | `study/system-design-interview/` | `progress-tracker.md` |

| Action | How | AI? |
|--------|-----|:---:|
| Track weekly progress | Open path's `progress-tracker.md` every Sunday | No |
| Fill in a week | Open `weeks/week-NN.md` → fill goals, notes, session log, retro | No |
| Create concept note | Wibey: `"I learned about [topic]"` — auto-routes to path's `concepts/` | Yes |
| Mark week done | Update week's frontmatter `status: completed`, mark tracker row ✅ | No |
| Create a new path | Wibey: `"create study path for [topic]"` — scaffolds full folder | Yes |
